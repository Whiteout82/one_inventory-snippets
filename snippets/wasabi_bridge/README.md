# How to use wasabi_bridge with one_inventory

Use this snippet to connect **wasabi_bridge** to **one_inventory**.

## 1) Copy inventory bridge folder

From this repository, copy the folder:

`snippets/wasabi_bridge/one_inventory/`

Into your **wasabi_bridge** resource at:

`wasabi_bridge/inventories/`

## 2) Restart resources

Restart your server (or restart **one_inventory** and **wasabi_bridge**).

## 3) Verify integration

Check console for bridge/export errors and test inventory-related bridge behavior.

If there are no errors, **wasabi_bridge** is now using **one_inventory**.
