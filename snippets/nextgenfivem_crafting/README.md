# How to use nextgenfivem_crafting with one_inventory

Use this snippet to connect **nextgenfivem_crafting** to **one_inventory**.

## 1) Copy inventory bridge file

From this repository, copy the file:

`snippets/nextgenfivem_crafting/src/inventories/one_inventory.lua`

Into your **nextgenfivem_crafting** resource at:

`nextgenfivem_crafting/src/inventories/one_inventory.lua`

## 2) Restart resources

Restart your server (or restart **one_inventory** and **nextgenfivem_crafting**).

## 3) Verify integration

Check console for bridge/export errors and test crafting and portable bench features.

If there are no errors, **nextgenfivem_crafting** is now using **one_inventory**.
